# Agent instructions

- This repository describes and installs the portable agent skills for clip-factory.
- Read `README.md` and `sources.json` before changing the installer or source pins.
- Never add cookies, API keys, OAuth data, machine-specific paths, model weights,
  caches, renders, or source footage.
- Install only into an explicit target project. Do not overwrite existing files
  or symlinks.
- Keep upstream source repositories pinned to reviewed commit hashes.
- Check upstream license terms before recommending commercial use.
