# Clip Factory — полная карта проекта для AI-агента

> **Назначение:** после прочтения этого файла агент должен уметь объяснить пользователю, что есть в репозитории, зачем нужен каждый компонент, как его установить, что уже работает, а что является только кандидатом. Язык ответа пользователю — русский.
>
> **Статус документа:** отражает содержимое репозитория на 11.11.2026, а не фактическую установку на устройстве. При сомнении проверяй реальные файлы, версии и доступность команд. Не называй компонент «установленным» только потому, что он записан в JSON.

## 1. Общая идея

Clip Factory — медиапроизводственный проект для людей и AI-агентов. Рабочее ядро: превращение длинного видео в короткие вертикальные ролики с автоматической расшифровкой, выбором моментов, кадрированием, субтитрами и QA. В репозитории также есть программные видеодвижки, навыки агентов, MCP-инструкции и реестры внешних программ для фото, видео, звука и 3D.

**Не путай четыре уровня:**
1. **Код проекта** — файлы действительно лежат в Git (например, `clip.py`, `remotion/`).
2. **Зависимость** — устанавливается локально (`ffmpeg`, `uv sync`, `npm ci`).
3. **Навык агента** — инструкция SKILL.md из внешнего репозитория, скачиваемая установщиком.
4. **Внешнее приложение/модель** — только ссылка в каталоге, пока не установлено и не проверено (ComfyUI, FreeField, Blender, облачные сервисы).

**Дополнение для исследовательских запросов:** [open-source-higgsfield-lab.md](open-source-higgsfield-lab.md) содержит 16 проверенных по upstream README конкурсных решений, их практические задачи, различия, способы сочетания и ограничения. Машинный список: `studio-addons/research-open-source-higgsfield-2026.json`. Это **не** установленный софт. `neuregex/freefield` и `droppedmyza/freefield` — разные репозитории; не путать!

**Дополнение — ComfyUI и профессиональная постобработка:** [comfyui-new-tools-2026.md](comfyui-new-tools-2026.md). Там 7 новых инструментов, включая агентный skill `nomadoor/comfyui-readable-node`, узлы PhotoDeblur, Director's Console, мосты Nuke/After Effects, Media и Camera Angle Selector. JSON: `studio-addons/research-comfyui-extensions-2026.json`. Все только изучены по README, не установлены. `scripts/studio_tools.py` подхватывает исследовательские JSON-реестры автоматически, включая конкурсный. Перед рекомендацией нужно выяснить тип задачи и проверить совместимость с установленным ComfyUI.

**Исследование VSR и MOSS-Image:** [moss-vsr-2026.md](moss-vsr-2026.md), структурированный каталог: `studio-addons/research-moss-vsr-2026.json` (33 записи). Здесь не только программы, но также модели/LoRA, источники сравнения и обучение. Обращай внимание на `verification`: некоторые Civitai/HF/Reddit/Pastebin источники не удалось прочитать; их описание дано по пользовательскому сообщению, не утверждай, что функционал доказан. Модель `KBlueLeaf/MOSS-Image-heal` относится к стабилизации чисел residual stream, а не к доказанному улучшению манга-композиции. `LTX-2.5` — генератор видео, не VSR-движок. `RTX` и `GAN` сами по себе не отдельные установочные апскейлеры. Общий `scripts/studio_tools.py` автоматически подхватывает все файлы `studio-addons/research-*.json` вместе с базовыми каталогами. Добавление новой подборки не требует изменения кода поиска.

## 4. Установка ядра и проверка

**Требования:** Git, Python 3.11+, `uv`, FFmpeg/ffprobe с libass, Node.js 22+, npm. Windows — рекомендуемый путь WSL2; для macOS не заявляй подтверждённую поддержку без теста. Системные команды и ссылки — в [installation-ru.md](installation-ru.md).

```bash
git clone https://github.com/VasilijEpishkin/clip-factory.git
cd clip-factory
uv sync
(cd remotion && npm ci)
(cd hyperframes && npm ci)
python3 scripts/studio_doctor.py --json
.venv/bin/python -m pytest -q
```

Для кадрирования лиц также нужна модель BlazeFace, команда скачивания есть в `docs/installation-ru.md`. Для загрузки по URL может потребоваться `yt-dlp`; для `highlights` — настроенный Hermes, Codex или Claude. Не обещай готовый запуск до проверки зависимостей и авторизации.

**Пайплайн:**
```bash
.venv/bin/python clip.py fetch URL --id demo
.venv/bin/python clip.py transcribe demo
.venv/bin/python clip.py highlights demo
.venv/bin/python clip.py edit demo
.venv/bin/python clip.py qa demo
```
Выходные файлы — `out/demo/`. Публикация не производится.

**Remotion:** `(cd remotion && npm ci)`, затем `cd remotion && npm run dev` (редактор) или `npm run render` (готовая композиция `AiflPromo`). В `remotion/package.json` закреплена версия 4.0.484.

**Hyperframes:** `(cd hyperframes && npm ci)`; в `hyperframes/package.json` указана зависимость `hyperframes: ^0.8.201`. В файле нет полноценного npm-скрипта рендера — сначала изучить upstream CLI и выполнить `npx hyperframes doctor`; не утверждать, что pipeline готов.

## 6. Внешние инструменты — полный перечень

Эти программы перечислены в `studio-addons/catalog.json` и `studio-addons/media-tools.json`. **Они не устанавливаются автоматически.**

**Генерация:** ComfyUI (графы AI-моделей), FreeField (эффекты и сценарии поверх ComfyUI), ComfyUI Manager (управление узлами), VideoHelperSuite (видео в ComfyUI), Wan2GP (локальная видеогенерация), Open Generative AI (отдельный desktop-интерфейс), ComfyUI AI Assistant (требуется дополнительная проверка конкретной интеграции), AgentY (upstream не установлен — не рекомендовать к установке).

**Фото и видео:** Rembg (фон), Upscayl и Real-ESRGAN (апскейл), IOPaint (удаление объектов), SAM 2 (маски), Depth Anything V2 (глубина), Video2X (видеоапскейл), auto-editor (монтаж по паузам), LosslessCut (быстрая нарезка), Kdenlive и Shotcut (ручной монтаж).

**Звук:** VoiceStudio (работа с голосом), OpenWhispr (диктовка), Audacity (ручной звук), Demucs (разделение источников), WhisperX (таймкоды и диаризация).

**3D и движение:** Blender (3D/анимация), MoCapAnything V2 (извлечение движения).

**Облачные сервисы, не устанавливаемые через pip/npm:** Canva, Higgsfield, HeyGen, YouMind, vidIQ, Metricool; доступность и тарифы проверять отдельно.

**Как устанавливать:** не угадывать команду. Сначала открыть [tools-ru.md](tools-ru.md), затем официальный upstream URL из соответствующего JSON. Устанавливать в отдельное окружение, если программа использует собственный Python/CUDA/модели. Проверить лицензию весов, совместимость, свободное место и ресурсы. Не запускать FreeField-установщик без понимания, какие модели и зависимости он загрузит.

## 7. Как агенту отвечать пользователю

Если пользователь спрашивает «Что есть в репозитории?»:
1. Кратко объясни назначение Clip Factory.
2. Раздели **имеющийся код**, **навыки из манифеста**, **внешние приложения из каталога**, **облачные сервисы**.
3. Назови конкретные инструменты и их назначение, сгруппировав по фото/видео/аудио/3D/агентам.
4. Для установки дай **один путь под выбранную задачу и ОС**, не предлагай устанавливать всё сразу.
5. Раздели подтверждённое содержимое Git и фактическую доступность на текущей машине; при необходимости выполни `python3 scripts/studio_doctor.py --json`.
6. Для любого нового инструмента сверяй JSON-каталоги; при изменении состава обновляй **этот документ и соответствующий реестр**.

## 8. Ограничения

- Никаких секретов, cookies, токенов, исходных медиа, весов и результатов рендера в Git.
- Никаких автопубликаций, платных вызовов или установки стороннего исполняемого кода без подтверждения.
- Не утверждать, что все перечисленные инструменты работают на конкретном устройстве.
- Не смешивать контекст отдельного ноутбука/дистрибутива с универсальными требованиями проекта.
- Не изменять рабочий `clip.py` и lock-файлы только ради реорганизации документации.
- Перед ответом об актуальном состоянии проверять файлы репозитория, а не полагаться на старый текст.

**Проверка каталога без установки:** `python3 scripts/studio_tools.py --json`. **Проверка окружения:** `python3 scripts/studio_doctor.py --json`.
