# Как подключить AI-агентов к Clip Factory

## Общий принцип

Агент **не получает отдельную копию** программ: он работает с тем же проектом и запускает доступные CLI-команды, навыки или MCP-инструменты. Графические программы без CLI/API могут требовать участия пользователя.

## 1. Установка проектных навыков

После [установки базового окружения](installation-ru.md) в корне репозитория:

```bash
python3 agent-stack/install.py .
```

Скрипт скачивает закреплённые в `agent-stack/sources.json` версии навыков и размещает ссылки в `.agents/skills/`. Это сетевое действие и выполнение сторонних источников: сначала ознакомьтесь с манифестом и установщиком.

## 2. Codex

Откройте корень проекта в Codex. Инструкции находятся в `AGENTS.md`, навыки — в `.agents/skills/`. Для запуска задач используйте документированные команды из `workflows/`.

## 3. Claude Code

Откройте корень проекта. Инструкции — в `CLAUDE.md`. Если ссылки ещё нет:

```bash
mkdir -p .claude
ln -s ../.agents/skills .claude/skills
```

Перед созданием ссылки проверьте, что `.claude/skills` ещё не существует. Не перезаписывайте существующие навыки.

## 4. Hermes

Используйте отдельный профиль Hermes для медиапроизводства. Передайте ему путь к корню проекта, инструкции `AGENTS.md` и выбранный workflow. Установка навыков в проект **не означает** автоматического подключения Hermes: путь к skills и способ вызова инструментов должны соответствовать версии Hermes на устройстве.

## 5. Что агент может делать

| Задача | Интерфейс |
| --- | --- |
| Найти программу | `python3 scripts/studio_tools.py --json` |
| Проверить окружение | `python3 scripts/studio_doctor.py --json` |
| Обработать длинное видео | `clip.py` и [workflow Shorts](../workflows/long-video-to-shorts.md) |
| Создать кадры в ComfyUI | Только после установки ComfyUI и настройки локального API/workflow |
| Управлять Blender | Через Blender MCP после отдельного подключения |
| Опубликовать видео | Только после явного разрешения пользователя и настройки сервиса |

## 6. Ограничения и безопасность

- Не устанавливать автоматически все программы из каталога.
- Не копировать ключи, cookies, OAuth-файлы и профили других агентов в Git.
- Не обещать генерацию через ComfyUI, если сервер не запущен и модель не загружена.
- Перед платной генерацией, внешней передачей материалов или публикацией запрашивать подтверждение.
- Проверять результаты рендеринга и QA, а не считать успешный запуск команды доказательством качества.
