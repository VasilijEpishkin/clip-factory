# Clip Factory — архитектура единой медиастудии

## Назначение
Единый переносимый workspace для **человека** (CLI, документация, внешние GUI) и **агента** (AGENTS.md, skills, MCP, CLI). Поддерживает изображения, видео, аудио, анимацию, 3D и публикацию через отдельно авторизуемые сервисы. Наличие записи в каталоге не означает установку.

## Границы
- **Core**: существующий проверенный pipeline `clip.py`, Python/FFmpeg, QA и тесты. Не ломать CLI.
- **Engines**: `remotion/` и `hyperframes/` — независимые рендереры с собственными lock-файлами.
- **Agents**: `agent-stack/`, `AGENTS.md`, `CLAUDE.md`, установленные локально `.agents/skills/`. Один pinned manifest для навыков.
- **Addons**: `studio-addons/` — опциональные инструменты и приложения; не устанавливать все автоматически.
- **Workflows**: `workflows/` — пошаговые рецепты с явными входами, выходами, ручным запуском и агентным исполнением.
- **Docs**: `docs/` — установка, инвентаризация, мосты и проектные решения.
- **Artifacts**: `work/`, `out/`, `vendor/`, модели, ключи, cookies и локальные настройки вне Git.

## Путь пользователя
1. Выбрать workflow в `workflows/README.md`.
2. Проверить зависимости в `docs/studio-stack.md` и статусы в `docs/studio-inventory.md`.
3. Запустить документированную команду либо использовать GUI соответствующего backend.
4. Проверить результат и сохранить проектные параметры. Публикация — отдельное подтверждаемое действие.

## Путь агента
1. Прочитать `AGENTS.md` и выбрать workflow.
2. Выполнить preflight доступности CLI/MCP, прав на входные материалы и необходимых credentials **без их вывода**.
3. Использовать только нужный backend, не ставить альтернативные тяжёлые стеки автоматически.
4. Создать артефакты и QA-отчёт; не публиковать без явного разрешения.

## Слои возможностей
| Направление | Базовый путь | Опциональные расширения |
| --- | --- | --- |
| Фото / графика | подготовка ассетов, FFmpeg-фильтры, внешние редакторы | Canva, Higgsfield, YouMind, ComfyUI |
| Видео / Shorts | `clip.py`, FFmpeg, Remotion, Hyperframes | MoneyPrinterTurbo, video-analyzer |
| Аудио | faster-whisper, FFmpeg | edge-tts, ElevenLabs, VoiceStudio |
| Анимация / 3D | Remotion | Blender + MCP, MoCapAnything |
| Исследование / упаковка | agent skills | YouTube Studio MCP, vidIQ, Metricool |

## Принципы реорганизации
- Перемещать рабочий код только вместе с обновлением импортов, путей, тестов и документации.
- Один источник истины на каждый тип данных: skills — `agent-stack/sources.json`, addons — `studio-addons/catalog.json`, проверки окружения — `docs/studio-inventory.md`.
- Сначала подтвердить работоспособность существующего pipeline, затем расширять интерфейс и функции.
- Не смешивать локальные программы, облачные подписки, MCP и skills в одну категорию «установлено».
- У каждого нового workflow должны быть цель, вход, выход, команда/интерфейс, зависимости, QA и критерий готовности.

## Консолидация
`clip-factory-agent-tool-stack` — прежний snapshot; канонический репозиторий: `clip-factory`. Перед удалением snapshot сверить все его tracked files и историю, затем архивировать или удалить отдельно. Не переносить README-заглушку поверх актуальных документов.
