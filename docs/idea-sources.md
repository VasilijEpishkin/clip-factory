# Источники идей и материалов

Список дал владелец канала (2026-11-05). Роль «референс» = брать идею, свет, композицию, подачу; сам файл в ролик не вставлять.
Роль «материал» = можно использовать в ролике, но только после проверки статуса прав у конкретного объекта и записи его в `docs/sources-used.md` (ссылка, лицензия, дата проверки).

| Сайт | Что там | Роль | Доступность на 2026-11-05 |
|---|---|---|---|
| AI Camera Movements (aicameramovements.com) | движения камеры и промпты для AI-видео | референс (промпты можно брать) | 200 |
| FrameThrower (framethrower.com) | кадры из фильмов, lookbook | только референс (кадры защищены) | 200 |
| FilmGrab (film-grab.com) | кадры из фильмов, композиция, цвет | референс | 200 |
| Are.na (are.na) | коллекции референсов | референс; права зависят от автора блока | 200 |
| Artkit (artkit.cc) | инструменты и ресурсы | референс | 200 (адрес artkit.cc, не .ai) |
| Eyecannndy (eyecannndy.com) | библиотека визуальных эффектов и операторских приёмов | референс | 403 для скрипта, открывать в браузере |
| ShotDeck (shotdeck.com) | поиск кинокадров | только референс | 403 для скрипта, открывать в браузере |
| Cosmos (cosmos.so) | подборки визуального вдохновения | референс | 200 |
| Letterform Archive (letterformarchive.org) | типографика, графдизайн | референс; оцифрованное открыто, права смотреть по объекту | 200 (без www) |
| Matchbloc (matchbloc.com) | винтажные спичечные этикетки | референс; материал только если объект в public domain | 200 |
| Public Domain Image Archive (pdimagearchive.org) | гравюры, карты, атласы, орнаменты | **материал** (public domain; смотреть пометку под изображением) | 200 |
| Internet Archive (archive.org) | видео, фото, аудио, архивы | **материал** (коллекции public domain, например `prelinger`; права смотреть по объекту) | 200, есть поисковый API |

Правила
- Кадры из фильмов (FilmGrab, ShotDeck, FrameThrower) в ролики не вставлять.
- На Internet Archive проверять поле лицензии/rights у каждого объекта, а не у коллекции.
- Поиск материалов Internet Archive: `https://archive.org/advancedsearch.php?q=collection:prelinger AND mediatype:movies&fl[]=identifier&rows=20&output=json`; загрузка через `yt-dlp` или прямую ссылку `https://archive.org/download/<identifier>/`.
