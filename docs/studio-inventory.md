# Инвентаризация стека медиастудии

Срез на 2026-11-10. Это карта ролей и границ воспроизведения, а не обещание,
что все интеграции сейчас авторизованы или доступны. Установка проекта описана
в [`studio-stack.md`](studio-stack.md); закреплённые источники skills — в
[`agent-stack/sources.json`](../agent-stack/sources.json).
Инструкции и каталог опциональных приложений: [`studio-addons/README.md`](../studio-addons/README.md)
и [`studio-addons/catalog.json`](../studio-addons/catalog.json).

## Как читать статусы

| Статус | Значение |
|---|---|
| В репозитории | Исходник/lock/manifest или pinned source входит в Git; большие модели, медиаматериалы и секреты сюда не входят |
| В текущем окружении | Команда обнаружена в PATH этой сессии; это не проверка функциональности |
| Интеграция агента | MCP, плагин или приложение подключается отдельно в Codex/Claude/другом клиенте; состояние зависит от устройства, аккаунта и авторизации |
| Опциональный кандидат | Не установлен и не входит в базовую воспроизводимую среду; для него приведено решение о пилоте |

### Плагины и MCP: область действия

Локальная инвентаризация от 2026-11-06 также перечисляла Claude Code plugins
`claude-seo`, `openseo`, Superpowers, ECC, claude-mem, Ponytail, document-skills,
example-skills, PubMed и BioRender. MCP-каталог там включает video-analyzer,
YouTube, Blender и пользовательские Tavily/DeepWiki/FFF и другие серверы.
Это исторический снимок клиентских настроек, а не содержимое portable repo;
конфиги с credential значениями не читаем и не переносим. Авторизацию и живую
доступность нужно проверять на каждом устройстве.

Состав `.agents/skills/` генерируется установщиком из pinned источников.
Текущая папка содержит 81 запись, включая `agent-reach`, который является
абсолютной ссылкой на `/home/vasilij/.agents/skills/agent-reach`; эта одна запись
не переносится между устройствами текущим manifests/установщиком. Остальные
проектные skills сгруппированы выше, без перечисления каждого из примерно 80
названий. Ревизии исходников зафиксированы в `agent-stack/sources.json`.

## Состояние команд в текущем WSL shell

Обнаружены в `PATH`: `ffmpeg`, `ffprobe`, `node`, `npm`, `npx`, `claude`,
`codex`, `hermes`. Не обнаружены в текущем `PATH`: `yt-dlp`, `uv`, `blender`,
`blender-mcp`, `youtube-studio-mcp`, `rclone`. Это проверка разрешения команды
из текущего shell, не полный поиск диска и не функциональный smoke test.

## Рекомендуемая схема добавления

1. Оставить текущий проектный runtime воспроизводимым через `uv.lock` и npm
   lock-файлы.
2. Если нужна локальная генерация, сначала вынести ComfyUI в отдельную машину
   или отдельный runtime и проверить один workflow FreeField на целевом GPU.
3. Пилот VoiceStudio отдельно от проекта; решение о фиксации принять после
   теста русского голоса и проверки лицензий моделей.
4. Open Generative AI, OpenWhispr, MoCapAnything и ComfyUI AI Assistant держать
   в каталоге опций до подтверждения нужного workflow.

Ключи, OAuth, cookies, пользовательские конфиги, веса моделей и медиаматериалы
не входят в репозиторий. Программная лицензия не заменяет проверку прав на
веса, голоса, обучающие данные, входные материалы и коммерческое использование.
