# Справочник инструментов: что делает каждый и как установить

**Обозначения:** **основа** — требуется для действующего конвейера; **дополнение** — необязательная программа; **облако** — отдельный сервис и учётная запись. Наличие в списке не означает, что программа установлена.

## 1. Монтаж видео и Shorts

| Инструмент | Зачем нужен | Как установить |
| --- | --- | --- |
| **FFmpeg / ffprobe** (основа) | Нарезка, кодирование, субтитры, обработка звука | Linux: `sudo apt install ffmpeg`; убедиться в наличии libass. [Сайт](https://ffmpeg.org/) |
| **clip.py** (основа проекта) | Автоматически превращает длинное видео в короткие вертикальные клипы | В составе репозитория; [пошаговая установка](installation-ru.md) |
| **Remotion** | Видео из React/JS-компонентов, титров и анимаций | В проекте: `(cd remotion && npm ci)`. [Сайт](https://www.remotion.dev/) |
| **Hyperframes** | Программный рендеринг HTML-видео | В проекте: `(cd hyperframes && npm ci)` |
| **Kdenlive** (дополнение) | Полноценный ручной монтаж на таймлайне | Xubuntu: `sudo apt install kdenlive`. [Сайт](https://kdenlive.org/) |
| **LosslessCut** (дополнение) | Быстро вырезать фрагменты без полного перекодирования | [Официальные релизы](https://github.com/mifi/lossless-cut/releases) |
| **Shotcut** (альтернатива Kdenlive) | Ручной монтаж, эффекты, переходы | [Сайт](https://shotcut.org/download/) |
| **auto-editor** | Автоматически убирать паузы и пустые участки | [Официальный репозиторий](https://github.com/WyattBlue/auto-editor); устанавливать в отдельное окружение |
| **Video2X** | Увеличение разрешения и интерполяция кадров видео | [Официальные релизы](https://github.com/k4yt3x/video2x/releases) |

**Совет:** для ручного монтажа выберите **Kdenlive**, а не устанавливайте одновременно Kdenlive и Shotcut. Для автоматического монтажа сначала используйте `clip.py`.

## 2. Генерация изображений и видео

| Инструмент | Зачем нужен | Как установить |
| --- | --- | --- |
| **ComfyUI** | Визуальный редактор цепочек AI-генерации: изображение, видео, маски, улучшение | [Официальный репозиторий](https://github.com/comfyanonymous/ComfyUI) и [инструкции](https://docs.comfy.org/installation/overview); отдельное Python/GPU-окружение |
| **FreeField** | Набор визуальных эффектов и генеративных сценариев, использующий ComfyUI | [Репозиторий](https://github.com/droppedmyza/freefield); следовать upstream README, **после** выбора ComfyUI; возможна загрузка больших весов |
| **ComfyUI Manager** | Установка и управление дополнительными узлами ComfyUI | [Репозиторий](https://github.com/ltdrdata/ComfyUI-Manager); устанавливать по инструкции для вашей версии ComfyUI |
| **VideoHelperSuite** | Импорт и экспорт видео внутри ComfyUI | [Репозиторий](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite); отдельные custom nodes |
| **Wan2GP** | Интерфейс для локальной генерации видео | [Репозиторий](https://github.com/deepbeepmeep/Wan2GP); отдельное окружение, требования к GPU уточнять для выбранной модели |
| **MoneyPrinterTurbo** | Автоматизированная генерация видеороликов | [Репозиторий](https://github.com/harry0703/MoneyPrinterTurbo); в проекте уже есть сценарий запуска `scripts/start_moneyprinterturbo.sh`; требует отдельной настройки API и источников |

**Важно:** ComfyUI — не сама модель, а оболочка выполнения графов. Для генерации нужны совместимые модели, которые скачиваются отдельно. FreeField — дополнение, а не замена ComfyUI. Для ноутбука без мощной дискретной GPU запуск тяжёлой генерации локально может быть непрактичен.

## 3. Обработка фотографий

| Инструмент | Зачем нужен | Как установить |
| --- | --- | --- |
| **Rembg** | Удаление фона с фото | [Репозиторий](https://github.com/danielgatis/rembg). Для CLI в отдельном окружении: `uv tool install "rembg[cli]"` |
| **Upscayl** | Увеличение разрешения фото в графическом интерфейсе | [Сайт и установщики](https://upscayl.org/) |
| **Real-ESRGAN** | Увеличение разрешения изображений, в том числе пакетная обработка | [Репозиторий](https://github.com/xinntao/Real-ESRGAN); отдельное Python-окружение или опубликованный upstream бинарник |
| **IOPaint** | Удаление объектов и восстановление областей изображения | [Репозиторий](https://github.com/Sanster/IOPaint); отдельная установка по upstream README |
| **SAM 2** | Выделение объектов и создание масок на изображениях и видео | [Репозиторий](https://github.com/facebookresearch/sam2); отдельное GPU-окружение и веса |
| **Depth Anything V2** | Создание карты глубины для параллакса, эффектов и композитинга | [Репозиторий](https://github.com/DepthAnything/Depth-Anything-V2); отдельная модель |

**Выбор:** убрать фон → Rembg; стереть предмет → IOPaint; повысить разрешение → Upscayl; получить точную маску объекта в видео → SAM 2.

## 6. Облачные сервисы

**Higgsfield, HeyGen, Canva, YouMind, vidIQ, Metricool** — это не локальные Python-библиотеки. Их подключают через соответствующий сайт, приложение или доступный коннектор. Тарифы, кредиты и авторизация отдельные; `uv sync` их не устанавливает.

## Что устанавливать первым

1. **Для Shorts:** FFmpeg + Python + `uv` + Node.js + `clip.py`; Kdenlive по желанию.
2. **Для фотографий:** Rembg; затем Upscayl или IOPaint под конкретную задачу.
3. **Для AI-генерации:** сначала проверьте видеокарту и память, затем ComfyUI; FreeField добавляйте после проверки базовой генерации.
4. **Для 3D:** Blender; MoCapAnything только если требуется перенос движения.
5. **Для агента:** сначала рабочая CLI-команда, затем skill/MCP; автоматическую установку тяжёлых инструментов не включать.

Список для машинного чтения: [основные дополнения](../studio-addons/catalog.json) и [другие инструменты](../studio-addons/media-tools.json). Для поиска: `python3 scripts/studio_tools.py <запрос>`.

**Ограничения:** отдельные инструменты ещё не проверены на вашем устройстве. Для каждой установки проверяйте актуальную инструкцию разработчика, совместимость ОС, лицензии программ и моделей. Не запускайте непроверенные custom nodes с доступом к токенам и личным файлам.
