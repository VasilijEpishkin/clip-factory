# Рабочие сценарии медиастудии

Это каталог **способов использования**, а не ещё один установщик. Пользователь может выполнять шаги вручную, агент — запускать те же команды. Необъявленные автоматизации и публикации запрещены.

| Сценарий | Вход | Выход | Статус |
| --- | --- | --- | --- |
| [Long video → Shorts](long-video-to-shorts.md) | видеофайл или разрешённый URL | 3 вертикальных клипа, QA | Реализован через `clip.py`; запуск зависит от окружения |
| Image edit / compositing | фото, маска, описание правок | изображение и параметры экспорта | Планируется; backend ещё не унифицирован |
| Faceless video | сценарий, озвучка, ассеты | ролик и project manifest | Планируется; отдельные генераторы уже каталогизированы |
| Character animation | character references, сцена, движения | последовательность/видео | Планируется; Blender/генераторы опциональны |
| Audio cleanup / dubbing | дорожка, язык, права | очищенная дорожка/дубляж | Планируется; FFmpeg/Whisper доступны как компоненты |

## Контракт нового сценария
Каждый workflow обязан описывать:
- **Входные данные** и права на их использование.
- **Результат** и критерии готовности.
- **Доступные человеку команды или GUI** и **эквивалентные шаги агента**.
- **Зависимости**, локальные/облачные затраты, необязательные интеграции.
- **QA**, путь вывода и поведение при ошибке.
- **Публикация** только как отдельный шаг с подтверждением.
