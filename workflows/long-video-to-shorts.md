# Long video → 3 Shorts

**Статус:** существующий pipeline, документирован; на новой машине необходим smoke test.

**Вход:** доступный с соблюдением прав URL или предварительно подготовленный локальный источник в `work/ID/`. **Выход:** три вертикальных видео в `out/ID/`, субтитры, метаданные и QA-отчёт.

## Ручной запуск
Из корня репозитория после установки зависимостей:

```bash
P=".venv/bin/python clip.py"
$P fetch URL --id demo
$P transcribe demo
$P highlights demo
$P edit demo
$P qa demo
```

Проверить `out/demo/qa.json` и сами видео перед дальнейшим использованием. Параметры и fallback CLI см. в корневом README.

## Запуск агентом
1. Проверить `ffmpeg`, `ffprobe`, `yt-dlp`, Python-окружение и доступный LLM CLI.
2. Уточнить ID проекта, входной URL и права на материал.
3. Выполнить те же пять команд, фиксируя ошибки и не обходя запреты источника.
4. Проверить QA и показать человеку готовые клипы; **не публиковать автоматически**.

## Критерий готовности
Есть три доступных для просмотра клипа, каждый прошёл проверки из `qa.json`; ошибки и пропущенные проверки явно указаны. Сам факт успешного выполнения команды не заменяет визуальный просмотр.
